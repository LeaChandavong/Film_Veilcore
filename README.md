# Film_Veilcore

##Phrase choc
- Un garçon de 14ans nommé Tristan se retrouve dans un autre monde remplie de monstres et entités.

##Type de projet
- Une série horreur animation 2D

##Public cible
- 16+

##Pourquoi ce projet
- C'est un mixe de genre horreur analogique et d'un thème esthétique nommé «Liminal space», espace liminal en français. Je travail sur cette idée depuis quelques années et continue toujours à le développer. C'est un de mes projets les plus importants que je souhaite qu'un jour il se fait reconnaître et aimer comme je l'aime.
